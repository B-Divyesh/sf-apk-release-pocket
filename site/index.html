A release, not an attachment

Check every handoff.

APK Release Pocket keeps the publisher fingerprint and device facts beside the download.

  1. 01 / inspect

    Read the APK

    Reads the package, version code, Android range, and processor support.

  2. 02 / verify

    Check the signer

    Checks the v2 signature and recalculates the signed content digest.

  3. 03 / publish

    Write the release page

    Writes an install page, QR link, checksums, release JSON, and prior releases.

Install the inspector

Install with one command.

The installer checks the downloaded archive against its published SHA-256 before installing arp.

release-counter
$curl -fsSL https://apk-release-pocket.sociobot.in/install.sh | sh
PSirm https://apk-release-pocket.sociobot.in/install.ps1 | iex
Then:arp release app-release.apk --out ./pocket --base-url https://downloads.example.com
Or try:arp demo

    The safety boundary

    No shortcuts around Android.

    ARP verifies and explains legitimate direct-install releases. It does not create signatures, disguise packages, collect device credentials, disable protections, or promise that a verified publisher is trustworthy. Users still choose whether to install.
