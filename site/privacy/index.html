Plain-language policy

Privacy

Effective August 28, 2026.

The CLI

The CLI reads APKs and writes release files on your computer. It contains no analytics or upload code.

The website

The site loads release details from the GitHub API. A successful response is saved in your browser for one hour.

The site does not load ads, analytics, or third-party fonts. The host may keep short access logs for security and delivery.

The demo

The demo uses bundled sample data. Demo approval notes use browser keys that start with demo:. Resetting or leaving the demo removes those keys.

Paid licenses

If you enter a license, the site saves it in this browser. The site sends it to api.sociobot.in for a license check.

Successful checks are reused for one day. Local approval notes also stay in this browser. Remove the site’s browser data to delete them.

Contact

Open an issue in the public repository ↗. Never post a license or private APK.
